# Artistic Style Taxonomy for Journal Figures

这份清单把“好看”拆成可复用的视觉变量，帮助在艺术语汇和科研可读性之间做选择。名称是论文图表的设计标签，不是历史色彩复原、文化来源证明或期刊官方规范。具体 HEX 见 [palette-atlas](palette-atlas.md)。

## 1. 先描述风格，再选颜色

| 维度 | 可选范围 | 论文图表中的含义 |
|---|---|---|
| 温度 | 冷、温、冷暖平衡 | 冷色更克制，暖色更适合少量强调；温度不能替代正负方向定义 |
| 饱和度 | 灰化、低、中、高 | 密集多面板优先低到中等；高饱和只保留给小面积重点 |
| 明度结构 | 同明度、阶梯明度、深浅双层 | 灰度输出主要依赖明度；分类色板至少保留两到三个明度层次 |
| 视觉重量 | 纸本轻、矿物中、墨色重 | 深色适合文字/描边或少量大面积块面，浅色需要边界和标签 |
| 质感暗示 | 水墨、矿物、青瓷、草木、纸本、编辑部 | 只影响色相和饱和度，不改变组别顺序和统计语义 |
| 构图密度 | 稀疏、普通、密集 | 密度越高，越应减少颜色数量、提高相邻明度差并固定图例 |

## 2. 风格家族总表

| 家族 | 关键词 | 首选图形 | 适合的类别数 | 主要风险 | 起步配方 |
|---|---|---|---:|---|---|
| 水墨矿物 | 墨蓝、青绿、赭石、藕红、灰紫 | 机制图、富集条形、多面板 | 4–5 | 深色和暖色在小点上过重 | `ink-mineral-a-sunlit` |
| 文人纸本 | 宣纸、石墨、灰青、茶褐、枣红 | 线图、网络图、注释密集图 | 3–5 | 灰色过多时层级不明显 | `ink-paper-literati` |
| 江南烟雨 | 雾青、藕粉、黛蓝、茶褐、灰紫 | 组织/细胞分类、分面图 | 4–5 | 浅粉和雾蓝缩印后发灰 | `jiangnan-muted` |
| 宋韵青瓷 | 青瓷、墨蓝、米灰、梅紫 | 正文主图、补充图、时间序列 | 3–5 | 纸灰不能承担关键组别 | `songyun-celadon` |
| 青花瓷 | 深钴、釉蓝、青白、暖米 | 热图注释、分组气泡、地图 | 3–5 | 蓝色相近，灰度层次不足 | `qinghua-porcelain` |
| 敦煌矿物 | 石青、朱红、石绿、金赭、沙紫 | 通路模块、富集、概念图 | 4–5 | 金赭和朱红不宜大面积浅填充 | `dunhuang-mineral` |
| 朱砂宫墙 | 朱砂、玉青、御赭、墨蓝、石灰 | 单一重点、分类标签、机制节点 | 3–5 | 红色容易被误读为风险/显著性 | `gugong-muted` 或 `ink-cinnabar` |
| 草木土色 | 森林、叶绿、土黄、陶土、梅紫 | 代谢、炎症、生态、器官图 | 4–5 | 多个绿阶在色觉差异下接近 | `botanical-earth` |
| 茶褐植物 | 茶褐、苔绿、米纸、木炭、果实红 | 生物过程、样本来源、实验流程 | 3–5 | 棕色和橙色灰度接近 | `tea-earth-botanical` |
| 北欧矿物 | 峡湾蓝、冰青、苔绿、赭石、灰玫瑰 | 白底高密度图、缩印图 | 4–5 | 冰青过浅，需深色描边 | `nordic-mineral` |
| 海岸矿物 | 海蓝、孔雀青、贝灰、珊瑚、沙金 | 环境、空间、单细胞分群 | 4–6 | 青绿与蓝色需用明度拉开 | `coastal-mineral` |
| 沙漠陶土 | 赭红、陶土、沙金、烟灰、干枣 | 热点、模块、空间或地理图 | 3–5 | 暖色连续使用会压低信息层级 | `desert-clay` |
| 高山湖泊 | 深湖蓝、雾青、松绿、岩石金、莓紫 | 纵向队列、生态、网络、轨迹 | 4–5 | 冷色小差异在投影或印刷中消失 | `alpine-lake` |
| 现代编辑部 | 深蓝、青绿、琥珀、玫瑰、紫灰 | 生物医学主图、跨面板结果 | 4–5 | 过度模仿“期刊色”而忽略数据语义 | `nature-muted` 或 `editorial-jewel` |
| 临床冷暖 | 海军蓝、板岩、青绿、珊瑚、芥末 | 病例/对照、临床指标 | 2–5 | 珊瑚和芥末应限制为强调 | `clinical-cool-warm` |
| 石墨铜色 | 石墨、银灰、蓝灰、铜、砖红 | 结构图、模型比较、重点结果 | 2–4 | 中性灰不足以区分多组 | `graphite-copper` |
| 单色强调 | 纸白、银灰、板岩、深墨 + 一个强调色 | 对照组 + 主结果、叙事图 | 1 个主组 + 背景 | 不适合所有组同等重要 | `monochrome-accent` |
| 柔和补充图 | 淡紫、雾蓝、青白、藕粉、杏色 | 补充图、流程或低密度示意 | 3–5 | 浅色在灰度和缩印下失去边界 | `pastel-journal` |

## 3. 按图表任务选择

| 图表任务 | 推荐家族 | 选择理由 | 避免 |
|---|---|---|---|
| 4–5 组定性柱形/箱线图 | 水墨矿物、现代编辑部、北欧矿物 | 有层次但不过分装饰，容易固定语义 | 全部高饱和、全部浅粉 |
| GO/通路富集条形或气泡 | 水墨矿物、敦煌矿物、草木土色 | 暖色可做少量模块强调，冷色承载主体 | 用红色直接暗示显著性 |
| 多面板组学结果 | 宋韵青瓷、江南烟雨、现代编辑部 | 低饱和、跨面板稳定、适合白底 | 每个面板独立换一套颜色 |
| 连续热图 | `paper-blue-sequential`、`jade-ochre-sequential`、`viridis.viridis` | 明度方向明确，适合强度数据 | 用定性色板插值或彩虹色带 |
| 正负效应/相关性 | `ink-cinnabar-diverging`、`qingzhu-diverging` | 有明确中点和两端方向 | 没有中点时强行使用发散色带 |
| 单一主结论 | 单色强调、石墨铜色 | 中性背景降低干扰，强调色突出主证据 | 给每个元素都加亮色 |
| 网络、机制和示意图 | 文人纸本、朱砂宫墙、敦煌矿物 | 描边和节点层级清晰，艺术感集中在大色块 | 细节点使用过浅颜色 |
| 地图和空间图 | 青花瓷、海岸矿物、沙漠陶土 | 地域语汇自然，但仍可使用连续/发散数据色带 | 装饰性底图抢过数据 |

## 4. 论文语境的配色语法

1. 先用白色或纸白背景承载版面，再用深灰/墨色承载文字、轴线和边界；背景不是一个数据类别。
2. 定性色板通常保留 4–6 个颜色；超过 7 类时优先直接标签、形状、线型或分面。
3. 暖色通常是强调角色，冷色通常是主体角色，但只有在图例中明确定义后才具有语义。
4. 透明度改变叠加密度，不应被用来制造新的类别；同一变量的透明度规则要跨面板固定。
5. 描边用于恢复浅色填充的边界，不承担组别识别；描边颜色尽量统一，避免每个组再引入一个颜色。
6. 同一图组中最多保留一个视觉焦点；若必须有两个焦点，使用明度和位置区分，而不是同时提高饱和度。

## 5. 组合和禁用规则

- **可以组合**：一个东方家族 + 一个中性灰系统；一个定性色板 + 一个同风格连续色带；一个主色板 + 灰色背景组。
- **谨慎组合**：敦煌矿物 + 高饱和荧光色、青花瓷 + 大面积暖红、柔和补充图 + 细小文字；只有在最终尺寸检查后使用。
- **不建议组合**：两套都包含相近青绿的家族直接拼接；把不同来源的色板按色相排序后当作一个“连续风格”；把红/绿或蓝/黄单独当作统计方向。
- **禁止误用**：把 `Nature`、`Cell`、`clinical` 等标签写成期刊官方色板或审稿标准；把文化色名写成历史复原结论；用颜色代替样本量、显著性或不确定性定义。

## 6. 最小风格说明模板

每次输出至少说明：

```text
style_family: <视觉家族>
keywords: <3–5 个形容词>
best_for: <图形与密度>
avoid_for: <不适用图形或介质>
roles: <背景 / 文字 / 主色 / 支持色 / 强调色 / 描边>
medium_adjustment: <白底、深底、缩印或印刷时的调整>
```
